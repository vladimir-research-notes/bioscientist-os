# Milestone notes

One file per completed milestone: `XX-<short-name>.md` (e.g. `02-ingestion.md`).

Each milestone note is written **after** the milestone is implemented and records:

- **Summary** — what the milestone delivered.
- **Deliverables** — the concrete files/CLI/tests added.
- **Design notes / decisions** — non-obvious choices and trade-offs.
- **Validation** — exact commands run and their outcome.
- **Status** — Complete, and the next milestone.

The authoritative *plan* for each milestone (what it should do) lives in
[`../PLAN.md`](../PLAN.md). These notes are the *record* of what was actually done.
