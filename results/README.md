# Results (regenerated, not committed)

This directory holds **reproducible** artifacts generated by the pipeline. Its
contents are **gitignored** — only this README and the directory skeleton are
tracked. Everything here can be regenerated from the committed fixtures.

```
results/
  raw/         local database (results/raw/bioscientist.db) from ingestion (M2)
  processed/   claims.{json,csv}, evidence_table.csv, eval_report.json, memo.md
  figures/     timeline, clusters, evidence matrix, link graph (M7)
```

## Regeneration

See `docs/REPRODUCIBILITY.md`. In short:

```bash
python3 scripts/01_ingest_fixtures.py
python3 scripts/02_build_index.py
python3 scripts/03_extract_claims.py
python3 scripts/04_build_evidence_table.py
python3 scripts/05_generate_visualizations.py
python3 scripts/06_run_eval.py
```

The canonical, committed copy of the headline numbers lives in `docs/RESULTS.md`;
the blobs here are derived and disposable.
