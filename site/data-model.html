Data model

Planned

Typed pydantic schemas with explicit provenance and epistemic typing.

Brief

Core schemas: Paper, Author, BiomedicalEntity, Claim, EvidenceItem, DatabaseRecord, EvidenceTable, ResearchQuestion, WorkbenchRun. Each derived object points back at its source.

Provenance and epistemic typing

  • data_source ∈ {fixture, cache, live} on every externally sourced object.
  • synthetic: bool marks fabricated fixture records.
  • extraction_method names the exact rule/model that produced a claim/entity.
  • support_conflict_unknown is a heuristic textual signal, not a biological verdict.
