Reproducibility

Scaffold

Everything in the default path is reproducible offline on a CPU.

Setup

python3.12 -m venv .venv && source .venv/bin/activate
pip install -e '.[dev]'
python3 scripts/00_check_environment.py     # offline environment report
python3 -m pytest -q                          # offline test suite

No network, no GPU, no paid API are required for any of the above.

End-to-end run (assembled across milestones)

python3 scripts/01_ingest_fixtures.py
python3 scripts/02_build_index.py
python3 scripts/03_extract_claims.py
python3 scripts/04_build_evidence_table.py
python3 scripts/05_generate_visualizations.py
python3 scripts/06_run_eval.py
