Reproducibility

Prototype

Everything in the default path is reproducible offline on a CPU.

Setup

python3.12 -m venv .venv && source .venv/bin/activate
pip install -e '.[dev]'
python3 scripts/00_check_environment.py     # offline environment report
python3 -m pytest -q                          # offline test suite

No network, no GPU, no paid API are required for any of the above.

End-to-end run (the full pipeline)

python3 scripts/01_ingest_fixtures.py            # M2  -> results/raw/bioscientist.db
python3 scripts/02_build_index.py                # M3  -> search index
python3 scripts/03_extract_claims.py             # M4  -> results/processed/claims.{json,csv}
python3 scripts/04_build_evidence_table.py       # M5  -> results/processed/evidence_table.csv
python3 scripts/05_generate_visualizations.py    # M7  -> results/figures/*
python3 scripts/06_run_eval.py                   # M8  -> results/processed/eval_report.json
python3 scripts/07_generate_memo.py              # M9  -> results/processed/memo.md
python3 scripts/08_llm_adapter_demo.py           # M10 -> offline LLM-adapter demo (no artifacts)

Each script is a thin wrapper over the corresponding biosci subcommand; see docs/REPRODUCIBILITY.md for the CLI equivalents, the determinism guarantees (byte-identical JSON across runs; a content-digest check on the database), and the optional matplotlib path for PNGs. All generated artifacts under results/ are gitignored and regenerable; nothing here requires the network, a GPU, or a paid API.

ImplementationAll milestone scripts (00_–08_) and the offline test suite are present; the end-to-end run reproduces the database, search index, claims, evidence tables, figures, evaluation report, and research memo. Final reproduction was re-verified at the M12 quality gate: deleting every regenerable file under results/ and data/cache/ and re-running the eight pipeline scripts returns each artifact byte-identical (ingestion content digest f040627…).
Tests / results274 offline tests pass (1 skipped). Committed: source, fixtures, gold labels, docs, site. Regenerated (gitignored): everything under results/ and data/cache/.
Open questionsDeterminism guarantees apply to the offline fixture/cache path only; the opt-in live connectors and the real LLM adapter are best-effort and off by default.
