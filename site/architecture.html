Architecture

Scaffold

One Python package, narrow testable subpackages, SQLite storage, a static site. No services, no GPU.

Brief

A single package src/bioscientist_os/ exposes a biosci CLI that wires subcommands to small subpackages. Each subpackage is independently importable and unit-tested. Storage is SQLite by default (stdlib, deterministic file output); DuckDB is an optional backend.

Pipeline

data/fixtures/ → ingest/ → storage/ (sqlite) ← databases/ (connectors)
                          ↓
                       search/  evidence/ (entities, claims, evidence tables)
                          ↓
                  visualization/   evals/
                          ↓
                 site/ + results/figures + research memo
