Optional LLM adapter

Done

A disabled-by-default, cost-guarded, mock-in-tests adapter — off the default pipeline path.

Brief

The workbench's methodological claim is that evidence can be made inspectable without an opaque model in the loop. So the language model is kept at arm's length: it is an optional adapter you can opt into for prototyping (e.g. comparing rule-based extraction's recall against an LLM, or polishing a memo's prose), not a step the default pipeline depends on. The pipeline (ingest → search → extract → evidence → memo) and the entire test suite run with no language model at all. The layer mirrors the database-connector layer — one tiny interface, an honest provenance stamp, a cache for determinism — plus the safeguard unique to spending money: a cost guard.

LLMAdapter
  ├─ MockLLMAdapter        deterministic, offline   → data_source=fixture   [the test backend]
  ├─ CachedLLMAdapter      read-through JSON cache   → data_source=cache     (data/cache/llm/, gitignored)
  └─ AnthropicLLMAdapter   opt-in, off by default    → data_source=live      [opt-in, never in CI]

Three safeguards

1. Cost guard (--max-cost-usd, dry-run). Every call is pre-priced and refused before any backend is touched if it would exceed the budget. The estimate prices the worst case (input tokens plus the full max_output_tokens); the actual spend is recorded from the backend's reported usage. The default budget is 0.0 — out of the box nothing that costs money runs, and the free mock is always authorized. --dry-run returns the estimate without making the call. Pricing is never hardcoded: the real adapter requires the caller to pass current pricing, since a guard is only honest with current prices.

2. Response cache. CachedLLMAdapter persists each completion as canonical JSON under data/cache/llm/ (gitignored), keyed by the request's content hash. A cache hit is stamped data_source=cache, costs $0, and charges no budget; a miss delegates to the inner adapter (which prices and charges) then writes a copy. A cached run of an expensive model spends money exactly once and repeats offline.

3. Least-trusted provenance. Anything a model produces enters at the lowest trust level: epistemic_level = unsupported_hypothesis, stamped llm:<adapter>. Model output never replaces a transparent baseline and is never silently promoted to observed metadata, an extracted claim, or an inferred relation (safety).

Mock (the test backend) and the opt-in Anthropic adapter

The MockLLMAdapter is deterministic, offline, and free by default; its output is a clearly-marked string ("[MOCK LLM OUTPUT …]"), never a real model answer. Determinism is what lets the whole contract — guard, cache, provenance — be exercised with no paid API and no network. The AnthropicLLMAdapter is the LLM analogue of the opt-in live connector: with allow_network=False (the default) it raises LLMDisabledError before its client is built or used; its client is injectable, so the parse/usage/provenance path is tested entirely offline; the real client is imported lazily and only on an opted-in call. It is best-effort and never run in CI.

Commands

biosci llm info
biosci llm complete "Summarize the senescence ↔ inflammation evidence." --task polish
biosci llm complete "expensive" --input-price 3 --output-price 15 \
    --max-output-tokens 4000 --max-cost-usd 0.0001        # refused by the cost guard
biosci llm complete "estimate" --input-price 3 --output-price 15 \
    --max-cost-usd 9 --dry-run                            # estimate, no call
biosci llm complete "cache me" --cache                    # 1st: fixture; 2nd: cache

The CLI uses the mock adapter only, to keep paid calls and API keys off the command line; the real adapter is used via the library (bioscientist_os.llm.AnthropicLLMAdapter). scripts/08_llm_adapter_demo.py runs the full contract offline.
