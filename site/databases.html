Offline-first adapters with a provenance field on every record.

Brief

A base connector interface with a required fixture-backed connector, a local cache, retry/error handling, and a data_source provenance field (fixture / cache / live). Live API connectors (PubMed, Europe PMC, OpenAlex, UniProt, Open Targets, PDB/AlphaFold) are optional, off by default, and never a test dependency.
