Visualizations

Done

Five figures that summarize the corpus and the evidence — data first, rendering optional.

Brief

Five figures, each split into inspectable data and optional rendering: a literature timeline, a topic-cluster summary, a claim/evidence matrix, an entity/database-link graph, and a support-vs-conflict table. The figure data is a pure, deterministic, provenance-carrying re-presentation of the workbench's own reports (M3 topics, M4 extraction, M5 evidence tables) — it never adds a new, unaudited computation. It is always written to results/figures/visualizations.json. PNG rendering uses matplotlib, an optional extra; when it is absent the PNGs are skipped (and figure tests are skipped) but the JSON is still produced, so the core path stays light.

python3 scripts/05_generate_visualizations.py            # data (+ PNGs if matplotlib present)
python3 scripts/05_generate_visualizations.py --no-render
biosci figures --db results/raw/bioscientist.db --json
pip install -e '.[viz]'                                  # enable PNG rendering

The evidence matrix defaults to the first stored research question (rq-autophagy-senescence); pass --question / --question-id to choose another. The matrix cell is the highest-confidence support label linking a paper to a question entity; none is an honest gap (no claim links them), distinct from unknown (a claim exists but its phrasing neither affirms nor negates).

Data, not just pictures

Because each figure is built from a frozen, JSON-serializable dataclass with a method, a data_source, and explicit denominators, the artifact a reviewer audits is the visualizations.json, not the PNG. The figure data is deterministic (byte-identical visualizations.json across runs); only PNG bytes may vary across matplotlib versions/fonts, and the network-graph layout is seeded for visual stability. This keeps the figures inside the same provenance discipline as the rest of the pipeline.

Tests pin determinism, the matrix cell rule, link-graph consistency, support-count agreement with the M5 tables, and the safety framing.
