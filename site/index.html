Overview

Scaffold

An evidence-centered research workbench that makes provenance inspectable, not opaque.

What it is

bioscientist-os ingests small biomedical paper corpora, normalizes them, searches and clusters them, extracts structured claims from abstracts using transparent (non-LLM) baselines, links those claims to biological entities and database records, and assembles evidence tables in which every cell carries explicit provenance.

The key artifact is not a summary. It is an auditable chain:

paper → extracted claim → biological entities → database links → support / conflict / uncertainty → visual report

The methodological question

How can a biomedical research assistant make evidence provenance explicit enough that scientists can inspect claims, supporting papers, database links, conflicts, and uncertainty — rather than receiving opaque summaries?

Every output separates four epistemic levels and never collapses them: observed metadata, extracted claim, inferred relation, and unsupported hypothesis.

Constraints

  • CPU-only by default (target: AWS m5.2xlarge-class); no GPU.
  • No paid APIs in the default path; connectors are fixture/cache-backed.
  • Tests run fully offline from small committed fixtures.
  • No large datasets, model weights, secrets, or caches are committed.
  • Any LLM integration is optional, off by default, mock-backed, cost-guarded.

Status

The project contract (plan, docs, website, permission policy, and an autonomous milestone runner) exists, and Milestones 0–2 have landed: the repository is an importable package with a runnable biosci CLI, the typed data model (pydantic schemas with provenance) plus small, clearly-labeled fixtures exist, and those fixtures now ingest into a deterministic local SQLite database. Search, extraction, and evidence tables land milestone by milestone. See the Milestones page for live status and Results for measured numbers.

The remaining pipeline subpackages are skeletons until M3+.
